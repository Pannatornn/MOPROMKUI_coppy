# การแนะนำแผนกสำหรับเดโมนัดหมาย

นี่คือกติกาคลินิกสมมติ ไม่ใช่แนวทางส่งต่อที่ผ่านการตรวจทางคลินิก และไม่ใช่การวินิจฉัย ก่อนใช้จริงต้องให้สถานพยาบาลกำหนดเกณฑ์และทบทวนผลแนะนำ

ผู้ใช้ต้องซักประวัติจนครบและเคสมีสถานะ ready ก่อนจอง ระบบผูกเคสจาก API ที่ผ่านการตรวจ patient token กับเซสชัน ไม่รับแผนกที่ผู้ใช้ระบุเอง และตรวจแผนกของแพทย์ซ้ำใน POST จองนัด เก็บเคสและเหตุผลประกอบนัดให้เจ้าหน้าที่เปิดตรวจได้

กติกาเดโม:
- สัญญาณฉุกเฉินจาก safety engine: แสดงห้องฉุกเฉิน/1669 และไม่เสนอคิวปกติ
- เคสเร่งด่วนหรือ escalated: ให้ติดต่อสถานพยาบาลเพื่อประเมินก่อน ไม่เสนอคิวปกติ
- เด็กและวัยรุ่น: กุมารเวช
- ตั้งครรภ์หรืออาจตั้งครรภ์: เวชปฏิบัติทั่วไปเพื่อประเมินภาพรวม
- หมวดอาการผิวหนัง: ผิวหนัง
- หมวดอาการทางท้องหรือโรคเรื้อรังที่ระบุ: อายุรกรรม
- หมวดอาการกระดูกและข้อ: กระดูกและข้อ
- หมวดอาการหู คอ จมูก: หู คอ จมูก
- หมวดอาการประจำเดือน/ตกขาว: สูติ–นรีเวช
- หลายหมวดหรือไม่ชัดเจน: เวชปฏิบัติทั่วไป

ใช้ข้อความจากผู้ใช้ ตรวจคำปฏิเสธพื้นฐาน และไม่ใช้ข้อความของ AI เป็นหลักฐานอาการ ประวัติเก่าในคำตอบติดตามไม่ใช้จัดหมวดอาการปัจจุบัน กติกานี้ยังไม่ครอบคลุมภาษาทุกแบบ จึงต้องผ่านบุคลากรก่อนใช้งานจริง

แผนกละ 2 หมอสมมติ ตารางต่างกัน คิวละ 30 นาทีภายใน 28 วัน หากแผนกไม่มีคิว ไม่สลับผู้ใช้ไปแผนกอื่น การเปลี่ยนเคสหรือลบเคสทำให้แบบจองเก่าใช้ยืนยันไม่ได้ นัดเก่ายังยกเลิกได้จากเซสชันเดิม

หลักประกอบการออกแบบ: [NHS: itchy skin](https://www.nhs.uk/symptoms/itchy-skin/) และ [NHS: acne](https://www.nhs.uk/conditions/acne/) อธิบายการประเมินเริ่มต้นโดย GP และส่งต่อแพทย์ผิวหนังเมื่อเหมาะสม ลิงก์เหล่านี้ไม่ได้รับรองกติกาแบ่งแผนกเดโมทั้งหมดข้างต้น
